# Product-Discovery Glossary

| Term | Definition |
|---|---|
| Experiment | Controlled test intended to answer a specific discovery question |
| Variant | Alternative version of an offer shown during an experiment |
| A/B Test | Experiment comparing two variants across visitor groups |
| Hypothesis | Testable prediction about visitor behavior |
| Exposure | Event recording that a visitor was shown a variant |
| Conversion | Defined visitor action indicating the desired response |
| Conversion Rate | Proportion of exposed visitors who convert |
| Experiment Metric | Measurement used to evaluate an experiment |
| Winning Variant | Variant supported by sufficient evidence to outperform another |
| Segment | Visitor group whose behavior may be analyzed separately |

The product loop becomes stronger:

Need → Offer → Hypothesis → A/B Experiment → Behavior + Signals → Opportunity → Decision → Implementation
