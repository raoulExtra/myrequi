# Knowledge Base

This directory contains project-specific learnings that are distinct from the general continuity.db system.

## Structure
- `principles/` — Core design and interaction principles
- `patterns/` — Reusable reasoning patterns extracted from work
- `trace_ids.json` — Mapping between project and system trace IDs

## Ownership
Project knowledge files are tagged with:
- owner: self_learn
- domain: project
- trace_id: <unique>
