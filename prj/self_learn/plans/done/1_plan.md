# Self-learn filesystem autonomy plan

status: completed

## objective
Make `prj/self_learn` a working self-improvement project that can keep its filesystem organized, update its own docs, and preserve a clear learning loop.

## steps
1. Keep the project tree canonical and easy to inspect.
2. Record every filesystem change in a small, readable doc.
3. Use `prj_tool.py` to verify the tree, phases, tags, and subdirs.
4. Add examples or tests whenever the project learns a new pattern.
5. Move completed work plans to `plans/done/`.
6. Add a tiny automation helper that syncs the filesystem and archives done plans.

## notes
- The filesystem is the project memory.
- `phase_0.md` is the entry point.
- `docs/learning-loop.md` defines the repeatable learning cycle.
