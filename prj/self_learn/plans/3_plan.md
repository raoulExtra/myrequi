# Self-learn glossary phase plan

status: active

## objective
Collect the glossary needed for a project like this and make the vocabulary future-proof.

## steps
1. Define the canonical project vocabulary.
2. Record terms in one future-proof glossary file.
3. Ensure the docs index surfaces the glossary automatically.
4. Verify the glossary is easy to extend without breaking older terms.
5. Keep the glossary short enough to stay useful.
