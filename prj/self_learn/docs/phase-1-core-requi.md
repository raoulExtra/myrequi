# Phase 1 core requirements

## core requirements
- [auto_ai] PH001-RC001: derive at least three candidate self-learn paths from the current project state and glossary.
- [auto_ai] PH001-RC002: score the candidates with explicit criteria, costs, and risks.
- [auto_ai] PH001-RC003: select one candidate and explain why it wins over the others.
- [auto_ai] PH001-RC004: write the selected path and review context into phase_1.md and docs/phase-1-outcome.md.

## acceptance criteria
### PH001-RC001
- PH001-RC001-AC001-AUTO: a candidate path is written down from the current project state.
- PH001-RC001-AC002-AUTO: the candidate path is derived from files, not from memory alone.

### PH001-RC002
- PH001-RC002-AC001-AUTO: the ranking criteria are explicit and visible.
- PH001-RC002-AC002-AUTO: the rationale explains why the chosen path wins.

### PH001-RC003
- PH001-RC003-AC001-AUTO: the review checks the goal, outcome, and modularity budget.
- PH001-RC003-AC002-AUTO: the review can say what should change if the path fails.

### PH001-RC004
- PH001-RC004-AC001-AUTO: feedback is written back into docs or the meta trace.
- PH001-RC004-AC002-AUTO: later phases can reuse the feedback without re-deriving it.
