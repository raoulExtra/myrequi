# Acceptance criteria for R1.10

## Requirement
- [R1.10 requirement](001.10-requi-table-rows-to-markdown-assets.md)

## Verification ideas
- A row is converted into a Markdown file.
- The file lives under `assets/<tablename>/`.
- The filename uses `<id>-<tablename>.md`.
- The output is readable as Markdown.
- Different rows of the same table map to distinct files by id.
- When all rows are exported, the target `assets/<tablename>/` folder is cleared before the new files are written.
