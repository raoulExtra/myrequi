# Part 02: Overlap classification

1. Normalize statement text for comparison without treating normalization as
   proof of equivalence.
2. Add an overlap report for exact and high-similarity candidates.
3. Classify candidates as intentional relation, duplicate, refinement,
   contradiction, or unresolved.
4. Use explicit links/provenance for intentional relations.
5. Leave unresolved records unchanged and report them for review.
