## Requirement

When a MIMAP markdown input is stored under a project's `docs/` folder, the generated HTML shall be routed to the same project under `out/`, preserving the project-relative path including the `docs/` folder.

## Details

- When the input MIMAP is inside `prj/<prj_name>/docs/`, the generated HTML shall be written inside `prj/<prj_name>/out/`.
- The `docs/` folder itself remains part of the output path below `out/`.
- The project-relative source path shall be preserved below `out/`, with only the file extension changed from `.md` to `.html`.
- Example: `prj/continuity_db/docs/000_phase/000-PH-001-MIMAP-thinking.md` shall produce `prj/continuity_db/out/docs/000_phase/000-PH-001-MIMAP-thinking.html`.
