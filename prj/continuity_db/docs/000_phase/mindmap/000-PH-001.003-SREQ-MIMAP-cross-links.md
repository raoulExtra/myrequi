## Requirement

The MIMAP HTML exporter shall add cross-links between related MIMAP HTML pages when a rendered MIMAP term matches another standalone MIMAP file in the same docs folder.

## Details

- The exporter shall detect sibling standalone MIMAP sources named like `000-PH-###-MIMAP-<term>.md`.
- When source text contains a matching term, including morphology-enriched spelling such as `(re)ason(ing)`, the HTML shall render a concept/MIMAP link after the enriched word.
- Morphology links remain inside the word; the MIMAP cross-link appears after the complete rendered word.
- Example: `(re)ason(ing)` shall keep `re` and `ing` morphology links and then append a MIMAP link to `000-PH-002-MIMAP-reasoning.html` when that sibling MIMAP exists.
- CREQ/SREQ/AC files with `MIMAP` in their title are not standalone concept MIMAP sources and shall not be used as cross-link targets.
