## Requirement

The MIMAP HTML exporter shall provide an all-folder regeneration mode so that adding a new MIMAP can refresh existing related MIMAP HTML files and their cross-links.

## Details

- The command shall support `--all-mimaps <folder>`.
- The folder scan shall include standalone source files named like `000-PH-###-MIMAP-<term>.md`.
- The folder scan shall exclude requirement/support files such as `CREQ`, `SREQ`, and `AC` files even if their filenames contain `MIMAP`.
- With `--overwrite`, the command shall regenerate each matching MIMAP HTML output.
- Regeneration shall update cross-links so older HTML files can link to newly added MIMAP terms when their source text mentions those terms.

## Example

```bash
python3 prj/continuity_db/imple/V00.00.01/mindmap/mimap_html.py \
  --all-mimaps prj/continuity_db/docs/000_phase \
  --overwrite
```
