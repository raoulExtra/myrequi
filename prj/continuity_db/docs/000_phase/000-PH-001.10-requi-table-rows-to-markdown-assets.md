# R1.10: Table rows are converted to Markdown asset files

The continuity_db project SHALL convert each selected table row into a Markdown file stored under `assets/<tablename>/` with the filename `<id>-<tablename>.md`.

When R1.10 extracts all rows from a table or view, it SHALL clear the target `assets/<tablename>/` folder before writing the new Markdown files.
When the id is numeric, the filename prefix SHALL be zero-padded to 4 digits.

## Traceability
- stakeholder need: outside observation should be able to inspect database rows as durable Markdown assets
- related phase: [phase_1](phase_1.md)
