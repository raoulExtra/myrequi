# MD-Project Header Pattern

**ID:** PAT-mdfilesystem

**Type:** Markdown Project Documentation Headers - Overview

## Header Patterns

This pattern defines which Markdown section headers should be in a overview file


### Supported Header Levels

Markdown headers with 1-6 hash prefixes are matched:
- `# Header` (Level 1)
- `## Header` (Level 2)  
- `### Header` (Level 3)
- `#### Header` (Level 4)
- `##### Header` (Level 5)
- `###### Header` (Level 6)

**Pattern (regex):** `^#{1,6}\s+.+`

### Headers
- General Headers
- Key Components
- Getting started
- Vision
