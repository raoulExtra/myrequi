# Acceptance criteria for R14-G

## Requirement
- [R14-G requirement](R14-G-graph-localhost-view.md)

## Verification ideas
- The demo project provides a localhost provider for a selected graph.
- The provider uses `--id` or `--name` selection.
- The provider serves the rendered graph on `localhost`.
- Opening the local root URL shows the graph as SVG in a browser.
- A reviewer can confirm the provider starts and serves the selected graph.
