# R4.1 checker examples

These files are sample inputs for the reusable R4.1 Python
checker.

Use `--root` once, then `--path` to switch the relative
folder for following file arguments.

- `requi_t_ok.md` — requirement file with `term[REF_EXISTS]`
  marker references
- `evidence_ok.md` — evidence file with the required
  extracted values and filesystem cues
- `config.json` — reusable JSON input for the checker
- `phase_1_1_ok.md` — link file that points at the R4.1
  requirement
- `command_example.md` — sample CLI call using `--root` and
  `--json-in`
