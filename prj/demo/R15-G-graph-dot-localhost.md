# R15-G: Graph tool can serve a DOT file as PNG on localhost

The demo project SHALL provide a `-dot <dotfile>` mode that converts the selected Graphviz DOT file to PNG with Graphviz and serves the PNG on localhost for browser viewing.

## Traceability
- stakeholder need: the demo should show an existing DOT file as a browser-friendly PNG on localhost
