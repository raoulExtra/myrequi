# 001-algo-from-need-clarify

This algorithm turns an initial user need into a clearer discovery request.

## Steps

1. Capture the user's first statement.
2. Detect the product or service type.
3. Detect the target geography.
4. Detect the desired quality level.
5. Detect the expected price range.
6. Detect special needs or constraints.
7. Ask the smallest missing question first.
8. Repeat until the need is specific enough to search.
9. Convert the clarified need into structured requirements.

## Output

A concise requirement set that can be used for search and comparison.
