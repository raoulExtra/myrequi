# 001-rule-file-naming

This file is named using the rule-file convention:

- prefix: `001`
- type: `rule`
- topic: `file-naming`
- extension: `.md`

## Naming pattern

`NNN-rule-<topic>.md`

### Example Explain

- `NNN` is a zero-padded number.
- `rule` is the category.
- `<topic>` is lowercase, hyphen-separated, and descriptive.
- The filename must match the document topic.
